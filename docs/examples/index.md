# Examples

This section provides hands-on examples of using EViz to create various types of visualizations. Each example includes the command-line syntax, expected outputs, and explanations of the generated plots.

## Prerequisites

Before running these examples, ensure you have:
- EViz installed and configured
- The `EVIZ_CONFIG_PATH` environment variable set
- Sample data files in the expected locations

```bash
python autoviz.py --help
```
